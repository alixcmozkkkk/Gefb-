# راهنمای نصب و اجرا

## ۱. نصب پیش‌نیازها
```bash
pip install -r requirements.txt --upgrade
```
حتماً از پایتون ۳.10 به بالا استفاده کن (به‌خاطر type hint هایی مثل `list[str]`).

## ۲. تنظیمات (فایل `config.py`)
قبل از اجرا این‌ها رو حتماً عوض کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات، از @BotFather بگیر |
| `BOT_USERNAME` | یوزرنیم ربات بدون @ |
| `ADMIN_IDS` | لیست آیدی عددی ادمین(ها). آیدی عددی خودتو از @userinfobot بگیر |
| `WITHDRAW_CHANNEL` | یوزرنیم کانالی که درخواست‌های برداشت توش پست می‌شه (ربات باید ادمینش باشه) |
| `STARTING_BALANCE` | موجودی اولیه‌ی هر کاربر جدید |
| `MIN_WITHDRAW` | حداقل مبلغ قابل برداشت |
| `REFERRAL_REWARD` | پاداش هر زیرمجموعه |
| `CURRENCY_SYMBOL` | نماد نمایش مبلغ (پیش‌فرض `$`) |

## ۳. اجرا
```bash
python bot.py
```
اگه پیام «ربات روشن شد...» رو دیدی یعنی همه‌چیز اوکیه.

## ۴. نکات مهم قبل از استفاده‌ی واقعی

- **ربات رو ادمین کانال `WITHDRAW_CHANNEL` کن** وگرنه نمی‌تونه پیام درخواست برداشت رو اونجا پست کنه.
- **کانال‌های عضویت اجباری** از اول خالیه؛ با دستور `/admin` (فقط برای ادمین‌ها) و گزینه‌ی «افزودن کانال عضویت اجباری» اضافه‌شون کن. برای هر کانالی که اضافه می‌کنی، **ربات باید ادمین اون کانال باشه** تا بتونه وضعیت عضویت کاربرها رو چک کنه.
- پرداخت واقعی (ارسال BNB به ولت کاربر) **دستیه** — ربات فقط درخواست رو ثبت و توی کانال نمایش می‌ده؛ خودت باید ارز رو بفرستی و بعد دکمه‌ی «✅ واریز شد» رو بزنی.
- دیتابیس (`bot.db`) کنار همین فایل‌ها ساخته می‌شه؛ ازش بکاپ بگیر تا موجودی/تاریخچه کاربرا گم نشه.
- دستور `/admin` فقط برای آیدی‌های داخل `ADMIN_IDS` جواب می‌ده؛ برای بقیه هیچ واکنشی نشون نمی‌ده.

## ۵. ساختار فایل‌ها
